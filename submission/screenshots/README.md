This folder contains visual evidence of the AURALIS prototype, objective validation, development environment, and repository state.

### Metrics Dashboard

Visual summary of the controlled AURALIS benchmark results, including:
- 90-case validation

### Additional Screenshots

The remaining screenshots document the working prototype, benchmark execution, development environment, repository and supporting project evidence.

## Evidence Scope

The screenshots are supporting visual evidence only.

The primary quantitative evidence is contained in:

- `../metrics/dfn2_inference_results.json`
- `../metrics/dfn2_laptop_benchmark.csv`
- `../metrics/benchmark.md`

The live demonstration screenshots should not be interpreted as a replacement for the controlled 90-case objective benchmark.

## Important Scope Note

AURALIS is currently a laptop-based AI/ML digital speech-enhancement prototype.

The project does not claim a completed physical acoustic ANC system, fabricated final PCB, or fully validated end-to-end 10 ms embedded streaming system at this stage.
